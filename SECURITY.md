# Security Policy

## Supported Versions

BookScreenshot is currently under active development. Security updates will be provided for actively maintained releases.

| Version | Supported |
|---|---|
| Development (`main`) | Yes |
| Stable releases | Depends on maintenance status |
| Older releases | No guarantee |

## Reporting a Vulnerability

If you discover a security vulnerability in BookScreenshot, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub issues.**

Instead, use GitHub's private vulnerability reporting feature:

1. Open the BookScreenshot repository on GitHub.
2. Navigate to the **Security** tab.
3. Select **Report a vulnerability**.
4. Provide details about the issue.

If private vulnerability reporting is unavailable, contact the repository owner privately through an appropriate channel.

## What to Include

When reporting a vulnerability, please provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or commit.
- Potential security impact.
- Relevant logs, screenshots, or proof-of-concept examples, if available.

Please avoid including passwords, access tokens, personal information, or other sensitive data in your report.

## Responsible Disclosure

Please allow reasonable time for the vulnerability to be investigated and addressed before publicly disclosing it.

We appreciate responsible security research and will make reasonable efforts to acknowledge valid reports, investigate the issue, and provide fixes where necessary.

## Scope

Security reports related to BookScreenshot are welcome, including issues involving:

- Arbitrary code execution.
- Unauthorized access to files or system resources.
- Unsafe handling of external modules or extensions.
- Path traversal and insecure file operations.
- Insecure handling of configuration files and session data.
- Vulnerabilities in dependencies bundled with the application.
- Remote monitoring and communication security, once implemented.

Thank you for helping keep BookScreenshot and its users safe.
