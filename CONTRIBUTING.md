# Contributing to BookScreenshot

Thank you for your interest in contributing to BookScreenshot!

Contributions of all kinds are welcome, including bug reports, feature suggestions, documentation improvements, and code contributions.

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Relevant error messages or logs.
- Your Windows and Python versions.

## Suggesting Features

Feature suggestions are welcome. Please explain:

- What the feature should do.
- Why it would be useful.
- How you think it should work.

## Submitting Code Changes

1. Fork the repository.
2. Create a separate branch for your changes.
3. Make your changes and test them.
4. Keep your code readable and maintainable.
5. Submit a pull request describing your changes.

## Development Guidelines

- Follow the existing project structure and coding conventions.
- Keep features modular where practical.
- Avoid unnecessary dependencies.
- Document new functionality and configuration options.
- Do not commit temporary files, personal settings, or generated output.

Thank you for helping improve BookScreenshot!
